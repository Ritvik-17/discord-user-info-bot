# User Information Bot  
![Discord](https://img.shields.io/badge/Platform-Discord-5865F2?logo=discord&logoColor=white)  

A lightweight Discord bot that displays detailed information about any user using their Discord ID.  
---

## 📌 About

User Information Bot was built to help server admins and users quickly fetch public details about a Discord account.  
With simple slash commands and a clean output format, it made user lookups effortless.

---

## ✨ Features

- Fetch detailed information about any Discord user  
- Clean and structured responses  
- Simple and easy-to-use slash command system  
- No configuration needed — invite and use

---

## 🛠️ Commands

| Command       | Description |
|---------------|-------------|
| **`/info`**        | Fetch full information for a user using their ID |
| **`/help`**        | Display help and instructions |
| **`/about`**       | Learn about the bot |
| **`/howtogetid`**  | Guide to retrieve a user’s Discord ID |
| **`/example`**     | View example output or usage |
